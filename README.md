# Mes romans

Espace d'écriture basé sur les agents et skills de
[creative-writing-skills](https://github.com/haowjy/creative-writing-skills)
(voir NOTICE), installés dans `.claude/`.

Premier pas : lancer le skill `project-setup` une seule fois, avant d'écrire.
Il collecte vos textes personnels pour créer vos fichiers de style.
Ensuite, démarrer avec l'agent `muse`.
